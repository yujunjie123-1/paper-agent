# Revision and Rebuttal

1. Preserve each reviewer comment verbatim and assign a stable comment ID.
2. Classify it as valid change, clarification, new analysis/experiment, misunderstanding caused by the manuscript, unsupported request, or conflict with another comment.
3. Map every comment to one of: accept and revise; accept and add evidence; explain existing evidence; respectfully disagree with evidence; or request editor clarification.
4. Create a traceability row containing comment ID, decision, rationale, action, owner, artifact dependency, manuscript locations, status, and validation.
5. Require approval before new costly experiments, scope expansion, or claims that change the study's preregistered objective.
6. Make the smallest sufficient revision and record before/after text or artifact hashes. Do not silently change unaffected conclusions.
7. Write the response point by point: quote/comment summary → direct answer → action/evidence → exact location.
8. Be respectful but specific. Do not claim “fixed” without a location and verification result.
9. Re-run relevant statistical, reproducibility, citation, and venue checks after revision.
10. Send the revised artifact through independent re-review. Keep unresolved items visible to the human author/editor.

Never fabricate an experiment or pretend that a requested analysis ran. If it cannot run, explain the constraint and bound the claim.
