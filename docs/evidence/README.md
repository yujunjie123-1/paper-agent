# Evidence index

This directory is the public index for artifacts that support project outcome statements.

Recommended subdirectories:

- `awards/` for certificates or official result pages;
- `deployments/` for release tags, deployment logs, and health-check records;
- `acceptance/` for acceptance notices or public publication links;
- `feedback/` for anonymized and consented user feedback summaries.

Keep personal identifiers, private messages, account credentials, and unpublished manuscripts outside the repository. Add a short Markdown record next to each public artifact with its date, source URL, and the claim it supports.
