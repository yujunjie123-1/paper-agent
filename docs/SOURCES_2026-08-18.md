# 2026-08-18 技术来源与决策影响

| 一手来源 | 本项目吸收的结论 |
|---|---|
| [OpenAI GPT-5.6 model guidance](https://developers.openai.com/api/docs/guides/latest-model) | Responses 作为模型层；PTC 只用于有界工具重任务；Multi-agent beta 仅用于独立并行分支；模型/reasoning/pro 必须用 eval 选择。 |
| [OpenAI orchestration](https://developers.openai.com/api/docs/guides/agents/orchestration) | 区分 handoff 与 agents-as-tools；只在能力、权限、prompt 或 trace 边界真正改善时拆 Agent。 |
| [OpenAI agent evals](https://developers.openai.com/api/docs/guides/agent-evals) | trace 用于定位失败层，dataset/eval 用于回归和版本对比。 |
| [LangGraph overview](https://docs.langchain.com/oss/python/langgraph/overview) | 低层持久执行、streaming、HITL 与 persistence 适合应用控制面。 |
| [LangGraph persistence](https://docs.langchain.com/oss/python/langgraph/persistence) | checkpoint/thread、pending writes recovery、replay 与 time travel 进入 V2 迁移/故障测试。 |
| [LangGraph interrupts](https://docs.langchain.com/oss/python/langgraph/interrupts) | interrupt 恢复会从节点开头重放，因此 interrupt 前的副作用必须幂等。 |
| [Microsoft Agent Framework Workflows](https://learn.microsoft.com/en-us/agent-framework/workflows/) | 图、类型化路由、superstep、HITL/checkpoint 作为备选 runtime 标杆。 |
| [Microsoft Durable Extension](https://learn.microsoft.com/en-us/agent-framework/integrations/durable-extension) | 在 Azure/Durable Task、跨进程长任务、可靠 streaming 成为硬需求时重新评估。 |
| [A2A 1.0 specification](https://a2a-protocol.org/latest/specification) | A2A 只作为跨服务 Agent 的 task/message/artifact 边界，不替代内部函数调用。 |
| [MCP 2025-11-25 specification](https://modelcontextprotocol.io/specification/2025-11-25) | MCP 用于 host/agent 到 tools/resources/prompts；consent 和权限由 host 管理。 |
| [Agent Skills open format](https://agentskills.io/home) | Skills 使用 `SKILL.md` 渐进加载；它是 SOP 而不是 sandbox。 |
| [ego-lite](https://github.com/citrolabs/ego-lite) / [ego-browser Skill docs](https://lite.ego.app/document/en/docs/skills) | macOS 使用已登录状态与隔离 Spaces；Windows 通过同契约 provider 降级，不伪装已运行 Ego。 |
| [Nature: Robin](https://www.nature.com/articles/s41586-026-10652-y) | 专职搜索/分析、多轨迹共识与 human/lab loop；同时支持稳定宏观工作流。 |
| [PaperOrchestra](https://arxiv.org/abs/2604.05018) | 写作 Agent 必须消费真实 pre-writing artifacts，不能从一句题目直接生成“投稿级论文”。 |

社区 Nature Skills 候选仍记录在 `config/external_skills.yaml`，不当作 Nature 官方政策，不经 commit 锁定、许可证和脚本/权限审计不自动安装。
